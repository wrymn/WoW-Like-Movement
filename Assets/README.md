# EDUCATION-ONLY, HUMAN-DIRECTED RESEARCH PROTOTYPE

> # AI-ASSISTED CODE, HUMAN-LED RESEARCH
>
> **AI was used to write implementation code, but this project was built under sustained human direction and supervision. Its behavior and values were personally measured, tested, debugged, corrected, and fine-tuned through many iterations. This is not autonomous or one-shot AI output.**

The purpose of these assets is to preserve independently measured, realistic character-animation, locomotion, and camera values observed in a retail game client. The scripts are experimental, prototype-quality demonstrations of those carefully validated values; they do not represent or claim to reproduce the retail client's internal source code or architecture.

Proprietary models, textures, animations, extracted data, paid Unity packages, and local demo content are intentionally excluded. Supply your own legally obtained dependencies and test assets.
